# Faktenbilanz – Quellen

Hier liegen die Quellenseiten zu den Videos von [@faktenbilanz](https://www.youtube.com/@faktenbilanz), veröffentlicht unter <https://faktenbilanz.github.io/quellen/>.

- Jedes Video bekommt eine eigene Seite (`<name>.md`), die Nummern entsprechen den Quellenangaben im Video.
- Eine Seite geht erst online, wenn das Video veröffentlicht wird.
- Korrekturen stehen mit Datum unten auf der jeweiligen Seite.

Nachgerechnet. Belegt.
